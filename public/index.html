TRANSPARÊNCIA POR PROJETO

Metodologia.

O que o Audita Voto verifica, como verifica e o que os dados não permitem concluir.

/ 01

Origem exclusivamente oficial

Descobrimos os recursos pela API do Portal de Dados Abertos do TSE. O arquivo CSV compactado vem do domínio oficial cdn.tse.jus.br, com validação SHA-512 contra o resumo publicado pelo Tribunal.

/ 02

Critérios determinísticos

As seções são agrupadas por UF, município, zona, número da seção, cargo e turno. Verificamos votos nominais repetidos ou o vetor completo de resultados, sem alterar os valores originais.

/ 03

Conferência aritmética

Para presidente, confrontamos a soma dos votos registrados com o comparecimento informado por seção e detectamos valores de comparecimento inconsistentes dentro do mesmo arquivo.

/ 04

Limite das conclusões

Resultados idênticos podem ocorrer naturalmente, especialmente em seções pequenas. Uma coincidência, por si só, não demonstra erro de contagem nem fraude. O sistema não identifica CPFs, eleitores nem escolhas individuais.

/ 05

Reprodutibilidade

O relatório identifica a URL oficial, o hash conferido, o arquivo lido, o instante de execução, a versão do processador, os parâmetros e as seções utilizadas. Os relatórios publicados podem ser consultados e exportados.

/ 06

Escopo da V1

Esta versão usa GitHub Pages para consulta e Supabase para histórico persistente de relatórios. O operador audita uma UF/turno por execução do GitHub Actions. Cruzamentos entre turnos e escala nacional ainda não estão implementados.

Princípio do projeto

O Audita Voto é independente, não afiliado ao TSE, não atribui irregularidades a candidatos ou partidos e não fornece inferências sobre votos individuais. A validação de hash atesta integridade em relação ao arquivo publicado, não a correção de todo o processo eleitoral.
